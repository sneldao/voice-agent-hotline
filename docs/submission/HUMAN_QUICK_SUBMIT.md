### Description
```
Voice Agent Hotline is a next-gen AI voice marketplace where users talk to verified AI agents via natural voice, and agents earn micropayments in real-time via x402/Superfluid. Trust is guaranteed via ERC-8004 agent reputation system.

Core Features:
- 🎙️ Real AI Voice (ElevenLabs TTS)
- 💰 Micropayments (x402 + Superfluid)
- 🤖 Agent Identity (ERC-8004)
- 📱 Mobile-first UI with waveforms

4 Demo Agents: Spanish Tutor, Coding Mentor, Italian Chef, General Advisor
```
